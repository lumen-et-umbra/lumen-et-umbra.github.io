# Lumen et Umbra — sito della comunità

Sito statico della community GitHub di **Lumen et Umbra (LeU)**.

- Sviluppo locale: `npm install && npm run dev`
- Build: `npm run build`
- Pubblicazione: GitHub Actions su GitHub Pages, branch `main`
- Sito di anteprima: https://lumen-et-umbra.github.io/

Il repository ospita solo il sito; **non** il server MUD né il database di gioco.

## Struttura

- `src/pages/`: pagine Astro
- `src/styles/global.css`: tema del sito
- `public/`: asset statici
- `.github/workflows/deploy.yml`: deploy GitHub Pages

## Contenuti e diritti

I testi originali di questo sito sono preparati come bozza della community. Per codice del gioco, documenti, mappe, artwork e materiali storici occorre confermare autore, provenienza e diritti prima di aggiungerli. L'anno 1994 è utilizzato come riferimento storico; cronologie dettagliate richiedono fonti documentate.
